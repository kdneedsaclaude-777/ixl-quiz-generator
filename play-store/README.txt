QUIZSPARK — GOOGLE PLAY LISTING TEXT (paste-ready)
==================================================

These are the TEXT fields for the Play Console. They are NOT the app bundle.

The app bundle (.aab) is a compiled Android file generated by PWABuilder
(https://www.pwabuilder.com) FROM YOUR LIVE WEBSITE — after the site is deployed.
You do not upload source code, and there is no folder to zip. See DEPLOY.md
"Phase B" for how the .aab is produced.

WHERE EACH FILE GOES IN PLAY CONSOLE
------------------------------------
SHORT_DESCRIPTION.txt   → Main store listing → "Short description" (max 80 chars)
FULL_DESCRIPTION.txt    → Main store listing → "Full description"  (max 4000 chars)
RELEASE_NOTES_en-US.txt → Release → "What's new in this release"   (max 500 chars)

IMPORTANT: Release notes and the full description are DIFFERENT fields in
DIFFERENT sections. You fill in BOTH — the full description in the store
listing, the release notes in the release you create. Don't put the full
description in the release-notes box.

For the Data Safety form and content-rating answers, see
docs/PLAY_STORE_LISTING.md.
