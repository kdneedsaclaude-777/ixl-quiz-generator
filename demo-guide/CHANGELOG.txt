────────────────────────────────────────────────────────────────────────
  HOW TO ADD A NEW ENTRY  (for whoever ships the next change)
────────────────────────────────────────────────────────────────────────

  1. Bump the version (semver: MAJOR.MINOR.PATCH).
       MAJOR  → breaking schema or auth change
       MINOR  → new user-visible feature
       PATCH  → bugfix or polish only
  2. Insert a new section at the TOP using the same banner format.
  3. Group lines under ADDED / CHANGED / FIXED / REMOVED / INFRA.
  4. Each bullet stands alone — someone skimming should grok it
     without reading the section above or below.
  5. If a role's feature set changed, also update that role's file
     in this folder (01-…txt through 05-…txt).
