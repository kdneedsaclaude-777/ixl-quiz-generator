┌──────────────────────────────────────────────────────────────────────┐
│  WHAT THEY SEE                                                       │
└──────────────────────────────────────────────────────────────────────┘

  /child/home          The home page
      • Big "Start practice" button — the first thing they see.
      • XP bar with level number (xpToLevel curve) + streak counter.
      • Daily practice goal card — progress toward the parent-set target.
      • Badge progress (next badge + how close they are).
      • Last quiz card with quick "Take another" link.
      • Time-lock screen if outside the parental window — friendly
        copy, shows when they can come back.

  /child/quiz/[quizId]    The quiz itself
      • One question at a time. No "skip", no "submit-all-at-end".
      • Big colorful answer buttons sized for tablet thumbs.
      • Immediate animated feedback after each tap
        (green check / red shake) with the why-wrong explanation.
      • Progress dots at the top show how many questions remain.
      • No timer by default (controlled by a feature flag).

  /child/quiz/[quizId]/results    The reveal screen
      • Animated score number counts up to the final percentage.
      • Itemized XP reveal: base XP = the score percent (100% = 100 XP =
        one level), plus bonuses (perfect, streak, first-of-day, daily
        challenge, comeback, test) — each shown as its own line.
      • Any new badges unlock with a popping animation. 15 badges total
        across First Quiz / Perfect Score / Topic Master / Speed Demon /
        Comeback Kid / Streak 3·14·30 / Level 5·10 / Test Ace / Daily
        Challenge / Centurion.
      • CTA back to home, or "Practice again".

  /child/progress       Their own dashboard
      • Score trend chart over time (their own version of the
        parent's chart — clickable points jump to that quiz's reveal).
      • All badges grid — earned ones lit, unearned ones dim.
      • Per-topic mastery bar (which skills are strong / weak).

  /child/account        Their own settings
      • Pick an avatar — choose an emoji avatar (or keep the auto one);
        it shows on home + the parent/tutor views.
      • Add or verify a phone number (Twilio dev fallback prints code
        to console).
      • Request a password reset email.
      • No way to change role, email, or delete account from here —
        the parent or admin does that.
